# muhdammar-azizan-portfolio

Professional portfolio website built with Next.js (App Router), TypeScript, Tailwind CSS and Framer Motion.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Editing content

All text, links and projects live in `src/lib/site.ts`. Put project images in `public/images/`.

## Deployment

Deploy on Vercel by importing this GitHub repository. Point the Hostinger domain to Vercel via DNS.
